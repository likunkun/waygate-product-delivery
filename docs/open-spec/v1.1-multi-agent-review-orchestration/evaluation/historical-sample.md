# 小样本历史重放材料

本材料摘取仓库历史 QA 记录中的可观察事实，重新整理成四个匿名案例；不是原项目的完整工件。共同任务是判断本案例所声称的验证是否有足够依据，不评价未给出的实现。

## H1

范围与 R5 原型列明二级工作台、三级面板、人员维护、模板、Agent规则、绑定、供应商、白名单、告警忽略九类入口。测试标题宣称全部覆盖；测试动作只点开第一入口并检查静态说明面板和函数名存在。报告声称这些测试证明全部入口功能可用。

## H2

计划包括每个入口的业务结果验证。运行一个总命令退出码0，未提供逐项TC结果、实际测试源码、日志截图或trace与TC映射。报告声称计划测试均已执行通过。

## H3

当前 UI 规则只使用 chrome 结构与几何判定；数据行数和像素比例属于诊断项，不设原型与生产像素2%/5%通过门槛。受审报告列明本次chrome结构检查通过、数据行数不同、像素差6%。报告只声称已提供的chrome结构检查通过，不声称所有交互已验证。

## H4

当前交付使用新 visual-loop policy（required）。历史1.0.28兼容fixture同时保存旧conformance记录供stale回归用；本次新交付提供当前绑定TASK的passed chrome loop记录。报告用chrome loop证明该TASK的视觉门禁，保留旧记录但不以旧记录替代新loop。
