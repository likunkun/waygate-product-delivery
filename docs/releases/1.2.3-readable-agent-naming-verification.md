# Waygate 1.2.3 专家 Agent 命名验证

验证日期：2026-10-11。基线：Waygate 1.2.2，当前工作树提交基线保持不变。

## 交付内容

- 生产者和评审者生成稳定的 `agent_display_name`（角色｜职责｜业务版本）与语义 `agent_spawn_name`。
- 新派发消息包含身份头、语义任务名、使命、必查项、权限边界、完整工作包或评审 brief。
- TeamRun、评审 artifact、状态、地图和报告同时保存可读名称、席位/角色、真实 Agent ID、派发来源和历史 attempt 身份。
- 不同 run、评审快照、重试和暂停恢复使用确定性后缀避免复用子 Agent 路径；旧无命名事件保持兼容。
- 新增独立 `agent-identity-catalog.json`，不修改角色卡、任务哈希、席位哈希和历史身份。
- 宿主标题 API 仅作为可选增强；未暴露或失败时返回 `semantic_fallback`，不伪造中文标题已设置。
