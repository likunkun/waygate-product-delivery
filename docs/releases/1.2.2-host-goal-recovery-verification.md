# Waygate 1.2.2 Host Goal 恢复验证

验证日期：2026-10-10。基线：1.2.1，提交 `52106036efea25131688f5815f49145bce718ad4`。

## 交付内容

- runtime 和分发包版本为 `1.2.2`；本机已安装并启用 `1.2.2+codex.20261010132746`。
- 新增 `prepare_host_goal_auto_recovery()` 和 `record_host_goal_auto_recovery(..., attempt_id=...)`。
- 初始故障与恢复 attempt 分开计数，最多三次恢复，退避为 5、15、30 秒。成功后保留本交付已消耗的预算；只有耗尽后的显式用户授权才能重置预算。
- 瞬时 unavailable、missing 和提前 complete 归档旧 binding 并生成新身份。探测发现精确匹配的旧 Goal 仍 active 时重新绑定；确认 missing/complete 后才执行 get/create/get。
- 明确的传输原因 blocked 返回宿主 Resume 契约并有限探测；新出现的业务阻塞原因覆盖原传输原因。未知 blocked、显式 block、用户等待和真实外部阻塞保留人工语义。
- 检查 owner、delivery、feature、launch package、授权、checkpoint 状态投影与 journal。归档 Goal 和幂等回调通过 hash-linked transition 追溯；回调消费时重新校验。
- prepare/record 使用 workspace lock 重新加载状态。等待和相同回调重放保持 canonical state 字节不变；暂停、放弃、闭包通过或新业务阻塞会阻止后续恢复动作。
- 状态输出、continuation 和 Stop guard 暴露恢复次数、attempt ID、原因、retry_at 和宿主调度要求。

## 宿主能力边界

插件只保存和返回 retry contract，没有内部 sleep 或计时器。当前 Paseo CLI 将 `--every` 转为五字段 cron，5/15/30 秒不能精确表示；已有 Goal 工具仅提供 get/create/update(blocked 或 complete)，没有 Resume 工具，也不允许覆盖未完成 Goal。

因此，本次交付完成了 runtime 恢复策略、持久化、门禁、回调契约、打包与安装；当前宿主下的秒级自动唤醒和 blocked Goal 自动 Resume 尚未打通。宿主需要按 `retry_at` 调度同一 owner thread，并提供原生 Resume 能力，之后才能验收完整的无人值守恢复。不得为了重建 Goal 提前伪造 complete 或创建新 owner 线程。
